# 🚀 AI Leader Projects

A collection of modern web applications built with HTML, CSS, and JavaScript. Created as part of the Google Generative AI Leader Badge holder portfolio.

## Projects Included

### 1. 📋 To-Do List Application

A feature-rich task management app with local storage persistence.

**Features:**
- Add, edit, and delete tasks
- Mark tasks as complete
- Filter by status (All, Active, Completed)
- Real-time statistics
- Local storage for data persistence
- Beautiful gradient UI with animations
- Fully responsive design

**Tech Stack:**
- HTML5, CSS3, JavaScript (ES6+)
- Local Storage API
- Font Awesome Icons

**Folder:** `todo-app/`

**Quick Start:**
```bash
Open todo-app/index.html in your browser
```

---

### 2. 🌤️ Weather Dashboard

A real-time weather application that fetches data from the OpenWeather API.

**Features:**
- Current weather conditions
- 5-day weather forecast
- City search functionality
- Geolocation support
- Favorite cities management
- Detailed weather metrics (humidity, wind, pressure, etc.)
- Beautiful weather-themed UI
- Responsive design

**Tech Stack:**
- HTML5, CSS3, JavaScript (ES6+)
- OpenWeatherMap API
- Local Storage API
- Font Awesome Icons

**Folder:** `weather-dashboard/`

**Quick Start:**
1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Edit `weather-dashboard/script.js` and add your API key
3. Open `weather-dashboard/index.html` in your browser

## Getting Started

### Prerequisites
- A modern web browser
- Optional: API key for Weather Dashboard (free from OpenWeatherMap)

### Installation

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/faridbarak/ai-leader-projects.git
   cd ai-leader-projects
   ```

2. **To-Do List App:**
   - Open `todo-app/index.html` in your browser
   - Start using immediately - no configuration needed!

3. **Weather Dashboard:**
   - Get API key from [OpenWeatherMap](https://openweathermap.org/api)
   - Edit `weather-dashboard/script.js`
   - Replace `YOUR_OPENWEATHER_API_KEY` with your actual key
   - Open `weather-dashboard/index.html` in your browser
